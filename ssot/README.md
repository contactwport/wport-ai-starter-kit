# ssot｜md as SSOT 範本

SSOT（Single Source of Truth，單一資料來源）：把資料用 Markdown 寫成一份，官網、文圖、履歷、文章都從這份長出來。資料改一次，全部跟著對。

用 Obsidian 的「開啟資料夾作為保管庫」打開這個資料夾。

| 資料夾 | 給誰 | 裡面有什麼 | 拿去做 |
|---|---|---|---|
| [`個人/`](個人/README.md) | 學生、求職者、個人品牌 | `我的資料.md`＋`我的資料/`（Eric 的公開資料當範例）、`resume.md`＋`about-me.md`（虛構人物林小範） | 個人網站、履歷（WPORT CLI）、表單 |
| `店家/` | 小店家 | `品牌資料.md`＋`品牌資料/`（範例店「竹籬笆咖啡」，虛構） | 店家官網、10 張社群文圖、貼文文案 |

規則：一份筆記講一件事，索引檔（`我的資料.md`、`品牌資料.md`）連到每份筆記；沒有的資料寫「待確認」，不要編。手機、地址、身分證、生日、銀行帳號不要放進公開 repo。
