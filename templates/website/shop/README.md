# 店家官網範本

`index.html` 是一份完整的形象官網（範例店「竹籬笆咖啡」，虛構），單一檔案、不用任何套件：

- 區塊：導覽列、主視覺、關鍵字跑馬燈、數字、本週優惠、招牌商品、品牌故事、客人好評、常見問題、怎麼買、營業資訊＋Google 地圖、頁尾統編
- 手機版：漢堡選單、好評可左右滑、底部「導航／私訊粉專」按鈕列、回到頂端按鈕
- 動畫：標題逐行浮現、捲到才浮現、照片慢慢推近、跑馬燈、卡片滑過浮起、問答展開；有開「減少動態」的使用者會自動關掉

用法：把整份貼給 AI，請它只把範例店的內容換成 `品牌資料`（SSOT）裡的資料，HTML 結構和 CSS 不動，只換 `:root` 的 `--accent` 主色。沒資料的寫「待確認」。

上線：建 `site/`，把改好的檔案存成 `site/index.html`，再用 Vercel CLI（`vercel --prod`）。
