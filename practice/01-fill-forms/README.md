# 練習一：離線表單（Word + Excel + 大小章）

**目標**：不自己打字，讓 AI 讀你的 Obsidian 筆記，填完一份補助計畫申請書並蓋上大小章。

```
01-fill-forms/
├── forms/      ← 空白表單（母版，別改）
│   ├── 補助計畫申請書_空白.docx
│   └── 個人資料彙整表_空白.xlsx
├── assets/     ← 印章圖檔（透明背景 PNG）
│   ├── seal-org.png        大章 520×520
│   └── seal-personal.png   小章 300×300
└── output/     ← 你的產出放這（自己建，已 gitignore）
```

## 準備

```bash
pip install python-docx openpyxl
```

**沒有附參考答案** —— 這是刻意的。做完拿 Step 3 的驗收清單自己對，或把兩份檔案丟回給 AI 說「幫我挑錯」。

**空白表單裡沒有 `{{佔位符}}`** —— 跟真實表單一樣，只有欄位標題和空格。AI 必須讀懂「聯絡電話」這欄該填什麼，而不是做字串取代。這是這個練習真正在考的事。

## Step 1 — 填 Excel（你的個人資料 SSOT）

先填這份，因為之後所有表單都從它抄。

跟 AI 說這句就好：

```text
用 ssot/個人/resume.md 的資料，填 practice/01-fill-forms/forms/個人資料彙整表_空白.xlsx，存到 practice/01-fill-forms/output/
```

（換成自己的資料，就把 `ssot/個人/resume.md` 改成你的 Obsidian 筆記路徑。）

**故意只給這一句。** 剩下的讓 AI 自己想：哪個欄位對應哪段筆記、沒有的欄位怎麼辦、要不要先問你。它想錯的地方，就是你要學的地方。

九個分頁各管一件事：

| 分頁 | 放什麼 | 為什麼要分開 |
|------|--------|-------------|
| 說明 | 這份檔案怎麼用 | 給未來的自己看 |
| 基本資料 | 姓名、生日、聯絡方式、地址 | 多了「可公開」欄 — 標 `Y` 的才適合放個人網站／品牌頁 |
| 自傳與敘事 | 一句話定位／300 字／800 字三個版本 | 申請書要 800 字、網頁欄位可能只給 300 字，先寫好三版就不用臨時砍 |
| 學歷 | 學校、科系、起訖 | 申請表常要「畢業年月」，履歷只寫年份不夠 |
| 工作經歷 | 職責 **和** 量化成果分兩欄 | 履歷要成果、申請表要職責，來源同一份 |
| 專業技能 | 類別／項目／熟練度／佐證 | 「佐證」欄逼你想清楚憑什麼說自己熟 |
| 語言與證照 | 分數、取得日期、效期 | 證照過期是投遞常見地雷 |
| 計畫與獎補助 | 申請過什麼、金額、狀態 | 補助計畫幾乎都會問「是否重複申請」 |
| 文件與用印 | 哪份文件要蓋哪個章、期限 | 交件前的檢查表 |

## Step 2 — 填 Word 申請書 + 蓋章

```text
用剛剛那份 Excel，填 practice/01-fill-forms/forms/補助計畫申請書_空白.docx，
用印欄蓋上 practice/01-fill-forms/assets/ 的大小章，存到 output/
```

申請書共十節，難度是遞增的：

| 節次 | 內容 | AI 要做的事 |
|------|------|-----------|
| 壹～參 | 基本資料、計畫基本資料、簡歷實績 | **抄** — 從 Obsidian 搬過來 |
| 肆、伍 | 計畫摘要（300 字）、**自傳（800 字）** | **寫** — 把散落的經歷組成一段有主張的敘事 |
| 陸 | **商業計畫書**：市場分析、產品服務、商業模式、客群通路、競爭差異、里程碑、風險因應 | **推論** — 從你的專業推出可執行的計畫 |
| 柒、捌 | KPI、經費概算 | **算** — 小計要加得起來，且等於申請金額 |
| 玖、拾 | 應檢附文件、切結與用印 | **蓋章** |

第伍、陸節是空白大框，AI 得靠上方標題判斷該寫什麼進去。**寫之前應該先給你大綱確認**——它若直接生出一堆市場數據，那就是在編。

**大章 vs 小章**

| | 是什麼 | 蓋在哪 | 尺寸慣例 |
|--|-------|--------|---------|
| **大章** | 公司／工作室的印信（單位全名） | 申請單位欄 | 3.5–4 cm |
| **小章** | 負責人／申請人的姓名章 | 負責人欄、騎縫、更正處 | 2–2.5 cm |

台灣實務上兩者通常成對出現：大章代表機構，小章代表簽核的人。

印章上的名字是虛構的示範，直接蓋在練習檔上即可。要換成自己的名字，用任何繪圖工具做一張透明背景的紅色方章都行。

## Step 3 — 驗收

- [ ] 每個欄位標題底下都有東西，該留白的 AI 有主動告訴你
- [ ] 沒有 AI 自己編的公司、學歷、金額、市場數據（引用統計要說得出來源）
- [ ] 自傳讀起來是你，不是通用模板
- [ ] 民國／西元年沒混（申請書用民國：西元 − 1911）
- [ ] 經費小計加總 = 合計，且等於「申請補助金額」
- [ ] 大小章都在、沒蓋掉文字
- [ ] 檔案在 `output/`，`git status` 看不到它

**加碼**：把申請金額改成 60 萬、期程改 12 個月，叫 AI 重算經費表 — 看它會不會連 KPI 目標值與里程碑一起調整。會的話，它是真的讀懂了計畫。

## 這個練習在教什麼

真正的重點不是 Word 技巧，是**單一事實來源**：Obsidian 改一次，申請書、Excel、履歷、個人網站全部跟著對。你手上有幾份互相矛盾的履歷，就是還沒建立 SSOT 的代價。

背後的 skill：[`gen-form-filler`](../../skills/gen-form-filler/SKILL.md)

## 注意

- 表單內容是**教學模擬**，不是任何機關的正式格式。真的要申請請到主管機關網站下載當年度表格。
- 印章 PNG 是模擬圖，**不是法定印鑑**，不可用於真實申請、契約或報稅文件。
- `output/` 內容不會進 git，但仍在你的硬碟上 — 含身分證字號的檔案請自行妥善保管。
