# 特質和例子

## 我堅持的做法

- 不教背語法：語法交給 AI，人負責想清楚流程、畫圖、寫規格
- 先想清楚再開幹：慢半小時規劃，省一整天返工
- 產出要能被 AI 和隊友直接接著做，不是寫漂亮話
- 課程結束時要有網址：學員帶走的是看得到、分享得出去的成果

## 別人最常稱讚我什麼

- 主動、敢接新東西：從教育系跑去修資科系的課，後來一路做到軟體公司的業務開發，再到創業

## 例子

- 台北扶輪青年服務團：大四加入，之後接下副團長、團長，帶 20 人團隊完成 24 項專案，也參與 2019 年尼泊爾 AED 計畫
- 聰電站第三場：對象是非技術背景，不教 Git 指令、不開 Terminal，第三小時結束時每位學員都有可分享的公開網址
